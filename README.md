# nyouna/homebrew-tap

A personal [Homebrew](https://brew.sh) tap for casks that are not (yet) available in the official `homebrew/cask` repository.

It currently has no casks. Earlier casks (`bing-wallpaper`, and `utm` pinned to 5.0.8) were removed once the official `homebrew/cask` versions covered them.

## Usage

```sh
brew tap nyouna/tap
brew install --cask nyouna/tap/<cask>
```
